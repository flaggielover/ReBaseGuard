# Cell 309 route matrix (Phase 0 → Phase 3; living document)

**Classes:** REJECTED, BLOCKED, INSUFFICIENT_EVIDENCE, RESEARCHABLE, PROMISING, FREEZE_READY.

Classification uses only committed scopes, theory and decoy evidence; no route was evaluated on 309. "Knockout scope"
refers to `CELL309_DOSSIER.md` §C.

**Reading a row.** Liability is motivation-provenance risk. Needs lists what is still required: data (payloads, new
real records), host (U1), U2 (P3 admissibility), U3 (floor extension; adoption only), or governance (a new real
execution under guard DENY).
