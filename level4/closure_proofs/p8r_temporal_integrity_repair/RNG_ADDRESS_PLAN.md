# P8R RNG address plan

**Frozen at the temporal anchor.**

## 1. The inherited property

Every raw draw is a **pure function of its address**. This is the repaired
Priority-6 standard (`p6r2b_gate9_crn_identity`), adopted for its property, not
merely its code: the address contains no live-set position, no execution order,
no stopping time, no branch order, no count of previously consumed draws, and
none of the quantities a comparison varies.

The P8 adjudication verified this layer as `P8_CRN_IDENTITY = PASS` and its
window extraction as `WINDOW_EXTRACTION = EXACT`. P8R inherits the
implementation and re-proves the property for its own address system rather than
citing P8 for it (`tests/test_crn_identity.py`, `scripts/rng_identity.py`).

## 2. Address shapes

Stopped-cycle field — used by `stopped.py` and by every calibration evaluation:

```
(SEED_NAMESPACE, tag_digest(experiment), tag(family),
 batch, row_block, block_index)
```

Deliberately **absent**: the detector, the window `m`, the window convention, the
lag depth. Those are exactly the axes P8R compares, so excluding them makes every
detector / window / convention comparison a common-random-number comparison on
identical innovation paths.

Chain field — used by `chain.py`:

```
(SEED_NAMESPACE, tag_digest(experiment), tag(family), tag(detector),
 m, cycle, tag(primitive_type), block_index)
```

Deliberately **absent**: `rho`, the shift size, the drift pattern, the
replicate's history. Those are the axes the chain experiments compare.
`primitives.chain_field_digest` takes no `rho` and no `shift` argument at all, so
it cannot depend on which variant asks; `tests/test_crn_identity.py` inspects its
signature.

Entropy namespace: `config.SEED_NAMESPACE = 0x50385F52_4D435201`. Distinct from
Stage D (`20261001`), P7 (`20260831`), P6R2b (`0x50365232_42435250`) and **P8**
(`0x50385F4D_43520001`). P8R is therefore an independent seed realisation of the
same estimands, not a replay of P8's field.

Integer family/detector codes are used throughout. Python's `hash()` of a string
is salted per process and never appears in an address.

## 3. Blocks and overflow

Values are materialised in blocks of `BLOCK_LEN = 128` observations for a band of
`ROWS_PER_BLOCK = 4096` replicates (`CHAIN_ROWS = 256` in the chain field),
generated by a counter-based Philox stream keyed only on the address.

Block `b` is generated independently of whether block `b-1` was ever generated,
so **overflow past the end of any pre-generated tape is not a special case**:
observation `t` lives at block `t // BLOCK_LEN`, offset `t % BLOCK_LEN`, row
`p % ROWS_PER_BLOCK` of row block `p // ROWS_PER_BLOCK`, for every `t`, forever.
`BLOCK_LEN` is deliberately small so that overflow is routine in the ordinary
experiment — the operating `ARL` is about 465, roughly four blocks per cycle —
rather than reachable only by a contrived test.

Row banding is an efficiency device only. The value delivered to replicate `r`
depends on `r // ROWS_PER_BLOCK` and `r % ROWS_PER_BLOCK`, both fixed a priori,
so which bands a run happens to *materialise* cannot change any delivered value.
`chain_monitor_column`'s `need` mask skips unneeded bands and returns `nan` for
them; the `live_set` identity check asserts directly that this changes nothing
for the replicates that are read.

## 4. The four address classes

This is P8R's addition to the inherited standard, and it is the structural half
of the repair.

| class | what may read it | when |
|---|---|---|
| `CAL_SEARCH` | threshold-search evaluations, in every stage including the frozen retry | while a threshold is still being chosen |
| `CAL_VERIFY_1` | one acceptance evaluation per family | once the threshold is final |
| `CAL_VERIFY_2` | one acceptance evaluation, for a retried family only | once the retried threshold is final |
| `PRODUCTION` | every scientific production result | after calibration is complete |

Every experiment tag is minted by `addressing.tag(cls, name)` as the string
`"p8r/<class>/<name>"`, and the address's second component is
`sha256(tag)[:8]` as a 64-bit integer. Two tags in different classes therefore
agree only if two distinct 64-bit SHA-256 prefixes collide.

`primitives.stopped_address` and `chain_address` call `tag_digest`, which calls
`class_of`, which rejects any string not minted this way — so a bare or foreign
experiment name raises `ValueError` rather than silently entering the address
space. `tests/test_address_separation.py` checks that with P8's own tag format.

### The frozen tag inventory

`addressing.TAG_INVENTORY` lists every tag the campaign is permitted to use:

```
p8r/cal_search/sr_arl0
p8r/cal_verify_1/sr_arl0
p8r/cal_verify_2/sr_arl0
p8r/production/arl0_check
p8r/production/gamma_e1
p8r/production/gamma_e5
p8r/production/chain_e3
p8r/production/drift_e4
```

Declaring the inventory before production makes the disjointness test
**exhaustive over the real campaign** rather than a spot check, and makes any tag
introduced later visibly absent from the anchored source digest (`I3`).

The independent reimplementation (`experiments/run_independent_repro.py`) mints
no tag: it deliberately draws from an entropy source outside this address system,
with a different bit generator (`PCG64DXSM`), a different stream construction and
a different window data structure, so that its agreement with production is a
genuine cross-check rather than a replay.

## 5. Required properties and where each is proved

| property | proof |
|---|---|
| calibration-search addresses cannot overlap calibration-verification addresses | `I4`; `test_class_pairs_never_share_an_address`; `test_executed_calibration_never_touched_a_verification_address` |
| calibration addresses cannot overlap production addresses | `I5`; `test_calibration_and_production_classes_are_disjoint` |
| variants intended for CRN pairing share exactly the intended primitives | `same_address_across_variants`; `test_chain_field_is_independent_of_rho_and_shift` |
| policy/variant identity does not alter shared primitives | the detector, `m`, convention, `rho` and shift are absent from the relevant address; `chain_field_digest` takes none of them |
| execution order does not affect primitives | `execution_order` (forward, reverse, and cache-cleared between every read) |
| live-set dependence does not affect primitive identity | `live_set`; `test_cache_size_cannot_change_a_delivered_value` |
| stopping-time divergence does not alter shared-address primitives | `stopping_time_divergence`: two detectors stop at different times, and each one's newest recorded window entry equals the value the address defines, exactly |
| overflow / address extension remains deterministic | `block_overflow`, probing block indices past 3 and up to `t = 1,000,000`, and the 4095/4096/4097 row-band boundaries |
| the four classes deliver different values at identical coordinates | `class_separation` |

## 6. Batch regions

Within a class, batch numbers separate purposes. They are frozen in `config` and
`tests/test_calibration_protocol.py` asserts their disjointness:

```
CAL_SEARCH     S1: CAL_S1_BATCH0 ..    S2: CAL_S2_BATCH0 ..
               retry: CAL_RETRY_BATCH0 ..
CAL_VERIFY_1   CAL_VERIFY_1_BATCH
CAL_VERIFY_2   CAL_VERIFY_2_BATCH
PRODUCTION     E1: E1_BATCH0 ..    E5: E5_BATCH0 ..
```

Note that `E1` and `E5` are separated **both** by tag and by batch region. Only
the tag separation is load-bearing; the batch separation is redundancy.
