## 1. The exact defect, not reinterpreted

The P6R2 CRN driver removed policy-dependent RNG **seeds**, but did not
establish literal fixed-path identity. The independent finding:

* only **cycle-0 identity** was actually tested;
* `all_paths_identical_across_variants = true` was **incorrectly inferred** from
  that cycle-0 check;
* later entering states differed across variants;
* later `zbar` / stopping paths differed;
* live-replicate sets differed;
* **overflow draws came from a shared vector RNG indexed by the current live
  set**, so overflow consumption and value→replicate mapping became
  variant-dependent;
* `cusum_m5` overflow counts differed materially across variants.

The offending line, `p6r2_literal_closure_repair/src/rebaseguard_p6r2/fixedpath.py`:

```python
x = overflow.standard_normal(idx.size)     # idx = CURRENT LIVE SET
```

## 2. What identity means here — and what it does not

**Required:** identical primitive **exogenous** randomness.
**Not required, and not attempted:** identical **endogenous** trajectories.

Once `s1` changes, the variants are *allowed and expected* to differ in
reference states, post-feedback innovations, stopping times, terminal windows,
`zbar`, live sets and subsequent policy decisions. Forcing those to match would
be the wrong experiment.

The contract is: for every

```text
(seed_namespace, detector, m, k, replicate_id, cycle_id,
 primitive_type, primitive_index)
```

the raw draw is bit-identical across all variants.

The address **must not** contain: `policy_id`; the sensitivity variant; the `s1`
multiplier; the current live-set position; a stopping time; branch order; or the
number of previously consumed draws.

## 3. RNG addressing scheme

Primitives are materialised in **blocks** of `BLOCK_LEN = 512` observations, one
block per `(seed_namespace, detector, m, k, cycle, primitive_type,
block_index)`, generated by a counter-based **Philox** stream keyed only on that
address. Observation `t` of replicate `r` in cycle `j` lives at block
`t // 512`, offset `t % 512`, row `r` — **for every `t`, forever**.

Separate addressable primitive types:

| type | use |
|---|---|
| `monitor` | raw observations feeding the detector |
| `fresh` | post-alarm fresh baseline observations |
| `init` | initialisation randomness (addressable even though this experiment uses `e_0 = 0`) |
| `aux` | auxiliary simulator randomness (unused here; addressable anyway) |

**Overflow is not a special case.** Block `b` is generated independently of
whether block `b-1` was ever generated, so a replicate needing observation
`t = 2457` gets block `4` offset `409` deterministically. `BLOCK_LEN` is
deliberately small so that overflow past the first block is **routine in the
ordinary experiment**, not merely reachable by a contrived test.

**No live-set indexing.** Each step reads the **full column** for all `n_rep`
replicates at address `(cycle, t)` and selects live replicates by boolean mask.
A replicate's value cannot depend on how many others are still active.

## 4. Planned tests (13 identity tests plus provenance)

1. monitor primitive at `(r, cycle, index)` bit-identical across variants;
2. fresh primitive bit-identical across variants;
3. initialisation primitive bit-identical across variants;
4. overflow primitive bit-identical across variants;
5. changing `policy_id` cannot affect a primitive draw (no such parameter exists);
6. changing the `s1` multiplier cannot affect a primitive draw;
7. live-replicate ordering does not affect a draw;
8. removing another replicate from the live set does not affect the rest;
9. same address queried in a different execution order returns the same value;
10. force `> 2000` observations and verify overflow identity;
11. primitive-stream hashes match across all four variants;
12. endogenous states are **allowed** to differ — the test must not require equality;
13. the old `all_paths_identical` semantics cannot silently reappear.

Plus: exact frozen-input hashes; no historical artifact modified; no policy
parameter anywhere in RNG addressing.

## 6. Calibration limitations that must survive the repair

6/8 cells converged; **`cusum_m2` did not**; **`sr_m3` did not**; sparse `s1`
evidence exists; fallback cells exist; the final large-pass refit is **not a
verified fixed point**. This experiment does **not** prove calibration
convergence — it measures only the empirical sensitivity of aggregate outcomes
to the declared `s1` perturbations under shared exogenous randomness. If the
true same-primitive sensitivity is **larger** than previously reported, it will
be reported as such.
