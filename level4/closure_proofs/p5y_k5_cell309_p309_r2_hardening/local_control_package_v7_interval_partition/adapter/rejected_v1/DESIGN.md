# Saved numeric lifecycle adapter, development only

`audit(root, private_decisions=None)` reads `root/offline/qpc.stdout.json` through replaceable `read(path)` and makes exactly two `rows(root/offline/qpc-prefix.csv)` passes. The bound driver must load the four exact module byte snapshots (adapter, interval_partition, account_saved_qpc, driver), snapshot summary bytes and enforce same verified CSV handle/hash/count across both passes. The fallback rows hook is ordinary file IO, NOT a provenance guarantee. No CLI automatically invokes audit.

Pass 1 retains every process/thread event with original one-based CSV data-row ordinal. `build_generations(events, low, high)` consumes `(opcode,qpc,numeric_id,identity,flags,row_ordinal)` and returns v4 generation tuples plus actual START/DCStart and END/DCEnd anchors, source row references, per-generation flags and unresolved histories. Same-QPC events, duplicate/overlapping Start, wrong End, missing End, backwards event order or overlapping derived generations invalidate the ENTIRE numeric ID; no earlier good generation survives a later conflict. Exact Start followed by one matching DCStart is corroboration, never an earlier birth. End-only including PID0 is unresolved. DCEnd bounds an actual existence anchor, not traceHigh. Source ordinal duplication or malformed source rows abort parsing.

Process flags are retained as individual observations under `(PID,generation ordinal)` even when ProcessKey repeats. Only consistent flags get a value; disagreement is explicitly flags-unknown, never OR-combined across generations.

Pass 2 closes per-CPU CSwitch spans and checks incoming/outgoing continuity. Every overlapping non-TID0 continuous span goes through `partition_switch_span` with ORIGINAL unclipped endpoints and complete per-ID generation lists (IDs may be subsetted for efficiency; generation rows/ordinals may not be filtered). v2 core binds a single original thread and process before clipping; the adapter cannot select later generations for the tail. PID0 gets no exemption. TID0 is separately counted as historical_idle_unproven, not proved idle. Unknown/ambiguous records remain explicit; discontinuity and backwards counts prevent any coverage claim. No ThreadEnd extension, timing tolerance, IRQ subtraction or host/guest deduplication is introduced here.

Optional private_decisions is opened with mode x and receives JSONL only for UNKNOWN or split decisions, including original CSwitch source rows and full local identity evidence. A later exception leaves an incomplete partial file, never a success result or retry target. No public raw identities. Public ticks/counts conserve accounted intervals; neither zero unknown nor a closed 60-second span authorizes complete coverage. Historical v4 reports stay unchanged.

Tests read only pinned source files then operate on tiny supplied events/rows, including production audit hooks. They do not execute the old 14-case suite, read actual numeric/ETL, query the host, run a VM/WSL/UAC or change services/keys. Python 3.12.14 is OFFLINE_ANALYSIS_TOOL, not P309 runtime qualification. I1-I7 OPEN, admission BLOCKED. Independent review and a bound driver are required before actual saved-data analysis.

Historical comparator: historical_lifetimes is an exact copy of v4 lifetimes body (function renamed); historical_owner preserves its nested owner body with maps passed explicitly. Source SHA256 3799e88d1726ba2a4e625d8e08decb3765a5bc36527bf92d8329fe81a81fa189. Tests compare both AST bodies. It evaluates the WHOLE clipped span as before, and never supplies a new identity. Four tick quadrants retain old-known/new-known, old-known/new-unknown, old-unknown/new-known (recoverable prefix) and both-unknown. Historical unknown total is measured anew only on later bound actual analysis, not asserted equal to 0.4392592 here. No historical report is changed.

Geometry scope is positive continuous non-TID0 CSwitch spans having positive overlap with the window; original full length = in-window + outside-window. Entirely outside spans and discontinuities are excluded from this explicit geometry scope. Core receives the original endpoints. Public comparisons conserve in-window non-idle ticks; TID0 and discontinuity are separate unknown classes. Optional private JSONL includes these unknown classifications as well, and for core decisions embeds the bound generation's original lifecycle tuple records plus one-based CSV data-row ordinals. Source lifecycle tuple schema is (opcode,qpc,numeric_id,identity,flags,row_ordinal); it is not the original eight-column row serialization. Any changed/split/unknown decision is retained; all-known unsplit unchanged decisions are omitted.

This is boundary identity accounting only: no IRQ subtraction, busy-utilization result, idle proof, guest allocation or formal coverage claim. CSV row count alone is not same-byte proof; the bound driver must enforce hashes on both passes over the same verified handle. Flags disagreement remains a separate identity-known/flags-unknown class. Tests may create and remove tiny synthetic JSONL within this C staging directory, solely to check CreateNew retention and original-row receipts.
