# Prior-art / novelty verification

This isolated campaign closes only the documentation/provenance requirement
for a systematic prior-art audit. It does not alter Stage F, the post-closure
global re-audit, D4, external validation, or any historical scientific result.

The machine-readable sources of truth are in `results/`. Human-readable
reports are generated mirrors. Live scholarly searches are evidence-
collection steps only; `./reproduce.sh` operates entirely from committed data.

The scoped decision distinguishes search closure from a positive novelty
claim. A closed audit may conclude that claims must be narrowed.
