**external to P5X**. Nothing here was caused by, or is repaired by, this
campaign. No file outside the P5X namespace was touched by P5X.


This is a legitimate adjudication commit by the repository owner. P5X does not

**(b) Untracked working-tree content was removed.** Two namespaces that existed
as untracked directories at both Checkpoint A and Checkpoint B are now absent
from the working tree **and** absent from git:


(content digests as recorded in
`results/integrity/protected_tree_manifest_pre.json`, taken at `eea2bfb`). They
were never committed, so git holds no copy and `git fsck` shows no recoverable
tree for them. The same action also removed P5X's own untracked
`results/ra_selftest.json`, which is why that artifact carries a later timestamp
than the run that produced it — see §3.

The most likely mechanism is a `git clean` (or equivalent) run alongside commit
`31132e8`. **P5X did not run it**, and P5X's commits (`db0781e`, `a2dd84d`,
`528908b`, `e02b5ce`) add only P5X paths.

## 3. Effect on `results/ra_selftest.json`

The mandatory `e = 0` self-test ran to completion **before** the diagnostics and
the stop-gate, as the frozen protocol requires, and passed all five checks. Its
JSON artifact was then deleted by the external clean. It was regenerated by
re-running the identical, deterministic script; the regenerated artifact is
byte-comparable in content to the original run, whose console output is
preserved in the session record (`wall_seconds 295.8`, `S4_gap 1.0598552e-9`,
`ghat(0,0) = 8.8817841970012523e-16`). The re-run changed no parameter and could
not: the self-test has no free parameters.

## 4. Consequences for gate `G11`

`G11` as written compares every tracked file outside P5X against the
pre-campaign manifest. It now fails, correctly, and for a reason that is **not a
P5X violation**. The honest disposition is:

* record the diff exactly (this document);
* **do not** re-baseline the manifest silently — that would destroy the gate's
  value;
* report `PROTECTED_TREE = FAIL (external cause, P5X not responsible)` rather
  than papering over it or claiming a pass;
* leave the adjudication of the external change to the repository owner.

`P5_IMMUTABLE` and `P5X_TREE_UNTOUCHED` — the two properties that actually
protect the science — both hold and are checked directly against git.

## 5. Recommendation

Commit the two disposition-audit namespaces if a copy exists outside this
repository; they are the only artifacts lost, and they were the authority for
launching P5X. If no copy exists, record their loss in the root status
documentation, citing the digests in §1(b). P5X takes no action on either, since
both lie outside its namespace.
